// External client communicates by email only
External Client > Exchange Online: emails and slot replies
Exchange Online > External Client: Teams invite and replies

// Experience to backend
Web Dashboard > CRM API
Teams Copilot Agent > CRM API
CRM API > Agent Orchestrator

// Orchestration
Agent Orchestrator > Ingestion Agent
Agent Orchestrator > Stage Classifier Agent
Agent Orchestrator > Summary and Next Action Agent
Agent Orchestrator > Scheduler Agent
Agent Orchestrator > CRM Writer Agent
Ingestion Agent > Scheduler Agent: new email text

// Agents to providers
Ingestion Agent > Mail Provider
Scheduler Agent > Calendar Provider
Stage Classifier Agent > Chat Model Provider
Summary and Next Action Agent > Chat Model Provider
Scheduler Agent > Chat Model Provider

// After human approval, the orchestrator sends and books
Agent Orchestrator > Mail Provider: send after approval
Agent Orchestrator > Calendar Provider: create or update after approval

// Primary paths
Mail Provider > Microsoft Graph: primary
Calendar Provider > Microsoft Graph: primary
Microsoft Graph > Exchange Online
Microsoft Graph > Entra ID: auth
Chat Model Provider > Azure OpenAI via Foundry: primary

// Fallback paths
Mail Provider > Synthetic EML Emails: fallback
Calendar Provider > Mock Calendar JSON: fallback
Chat Model Provider > Ollama Local Model: fallback

// CRM store behind repository interface
CRM Writer Agent > CRM Repository
CRM API > CRM Repository
CRM Repository > CRM Store: adapter - Azure SQL, Dataverse or SQLite
CRM Repository > Audit and Trace Store: audit entries

// Observability
Backend > App Insights
