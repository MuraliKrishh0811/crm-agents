How to use: open a Claude Code session in this repository and paste **one prompt at a time** (each prompt is inside its own text block and is self-contained, including the standing rules). If you change the checklist, run `python3 tools/generate_prompts.py` to regenerate the prompts. Work through the sub-slices in order: 0, 1a to 1d, 2a to 2d, 3a to 3f, 4a to 4h, 5a to 5d, 6.

Contents: 1 session start; 2 one prompt per sub-slice (0, 1a to 1d, 2a to 2d, 3a to 3f, 4a to 4h, 5a to 5d, 6); 3 review; 4 debugging; 5 resume after a break.

Rules that every prompt repeats (so each can be pasted alone): plan first and wait for approval; real code only (R1); work only in the named sub-slice; run the tests and the smoke test and report real output; stop and ask at every standing trigger S1 to S9 of the overall plan, section 4; `.env` per R7 (Claude never opens, prints or searches it; the application's own loader may read it when tests run); do not commit (you commit after Claude shows `git status` and proposes a message).
